# FAO Niger Agroclimate Risk Tools 0.5.0

A QGIS plugin that builds agropastoral drought risk maps for Niger from ACMAD drought data and ESA WorldCover land cover, adds them to the map with styles, and shows statistics by risk class and by region. This release makes the first run take seconds: ACMAD's prepared exposure and Niger's regions are fetched for you, so there is nothing to download by hand.

**Pre-1.0.** The exposure cut-offs, the class mapping and the weights are provisional until FAO and ACMAD review them, so treat the maps as a screening tool. See the [known problems](https://github.com/ACMAD-Niamey/fao-niger-agroclimate-risk-tools/blob/v0.5.0/CHANGELOG.md#known-problems).

## What is new since 0.3.2

- **First run in seconds.** With *Use ACMAD's prepared exposure* ticked (the default), the panel fetches four small files (about 66 KB) instead of building exposure from land cover (about 430 MB and 5 minutes). Untick it to build from land cover yourself.
- **Region summary in one click.** *Summarise by region* uses ACMAD's copy of Niger's 8 administrative regions (OCHA, CC BY-IGO) by default, or any polygon layer of your own.
- **A table you can scroll and copy.** Every tab scrolls, the region table shows all its rows, and *Larger table* opens every figure in a window with a **Copy table** button for pasting into a spreadsheet.
- **A language model description that works with real services.** *Test connection* tells you whether the address, the key or the model is wrong; answers are streamed so slow reasoning models are not cut off after a minute; an optional *Extra request fields* setting turns thinking off for models that need it; keys pasted with stray spaces are cleaned, and a rejected key is described (length, ending, easy-to-confuse characters) without being shown. It is off until you set it up.
- **Easier to find.** A button in the message QGIS shows when the plugin loads, a Processing Toolbox entry (*Agroclimate Risk panel*), the toolbar icon and the Plugins menu all open the panel. A part of the plugin that fails to load is reported in a red message.
- **More documentation:** [installation](https://github.com/ACMAD-Niamey/fao-niger-agroclimate-risk-tools/blob/v0.5.0/docs/installation.md), [troubleshooting](https://github.com/ACMAD-Niamey/fao-niger-agroclimate-risk-tools/blob/v0.5.0/docs/troubleshooting.md) and the [language model guide](https://github.com/ACMAD-Niamey/fao-niger-agroclimate-risk-tools/blob/v0.5.0/docs/language-model.md).

## Install or update

1. Download `fao_niger_agroclimate-0.5.0.zip` below. Do not unzip it.
2. In QGIS 3.28 or later: `Plugins > Manage and Install Plugins > Install from ZIP`, choose the file, and enable the plugin.
3. **Restart QGIS** if you are updating from an older version.
4. Open the panel from the message QGIS shows, the toolbar icon, or `Plugins > FAO Niger Agroclimate`, and press **Run and add to map**. The first run offers **Prepare exposure, then run**.

Your settings are kept when you update. The walkthrough with screenshots is in [using the panel](https://github.com/ACMAD-Niamey/fao-niger-agroclimate-risk-tools/blob/v0.5.0/docs/using-the-panel.md).

## Requirements

QGIS 3.28 or later (it runs on QGIS's own Python 3.9) and an internet connection to reach ACMAD. No other software needs installing.
