# FAO Niger Agroclimate Risk Tools 0.3.2

The first release: a QGIS plugin that builds agropastoral drought risk maps for Niger from ACMAD drought data and ESA WorldCover land cover, adds them to the map with styles, and shows statistics by risk class and by region. The command-line script and the shared code behind it are included.

**Pre-1.0.** The exposure cut-offs, the class mapping and the weights are provisional until FAO and ACMAD review them, so treat the maps as a screening tool. See the [known problems](https://github.com/ACMAD-Niamey/fao-niger-agroclimate-risk-tools/blob/v0.3.2/CHANGELOG.md#known-problems).

## Install

1. Download `fao_niger_agroclimate-0.3.2.zip` below. Do not unzip it.
2. In QGIS 3.28 or later: `Plugins > Manage and Install Plugins > Install from ZIP`, choose the file, and enable the plugin. Restart QGIS if you are replacing an older version.
3. Open the panel from the message QGIS shows, the toolbar icon, `Plugins > FAO Niger Agroclimate > Open Agroclimate Risk Panel`, or the first entry of the *FAO Niger Agroclimate* group in the Processing Toolbox.
4. Press **Run and add to map**. The first time, choose **Prepare exposure, then run** (about 5 minutes, needs internet, once only).

The walkthrough with screenshots is in [using the panel](https://github.com/ACMAD-Niamey/fao-niger-agroclimate-risk-tools/blob/v0.3.2/docs/using-the-panel.md).

## What is in it

- A period list showing only what ACMAD has published, latest first and selected by default.
- The current drought indicator (CDI) or the seasonal combined hazard, with exposure from cropland and rangeland.
- A results tab with a class chart and table, and a summary by region for any polygon layer.
- An optional language model description of the results, off by default.

## Requirements

QGIS 3.28 or later (it runs on QGIS's own Python 3.9) and an internet connection to reach ACMAD and, for the one-time exposure step, the ESA WorldCover files. No other software needs installing.
